# HamGNN predictions to NAC

Prepare eigenstates from existing HamGNN Hamiltonian predictions and matching
graph overlaps. Use the calibrated AO overlaps generated by the
[ABACUS overlap step](../abacus/README.md#generate-adjacent-frame-ao-overlaps),
then finish with [common NAC projection](../common/README.md).

| Script | Role |
| --- | --- |
| `wfc_hamgnn.py` | Per-frame graph and predicted Hamiltonian → `eigen.npy`, `wfc.npy` |
| `hamgnn_wfc.py` | Internal Gamma-point matrix assembly and CPU eigensolver |
| `abacus_basis.py` | Internal orbital masks for HamGNN graphs using ABACUS basis conventions |

## Dependencies and setup

Use Python 3.9+ with NumPy, SciPy and HamGNN's environment, including PyTorch,
PyTorch Geometric and pymatgen. Graph files contain pickled objects; use trusted
files produced by your own HamGNN workflow. Model training, graph generation
and prediction remain in HamGNN.

Set these example paths and frame range for your calculation:

```bash
WORKFLOWS=/path/to/CA-NAC/workflows
WFC_PYTHON=/path/to/hamgnn-environment/bin/python
GRAPH_ROOT=/path/to/hamgnn-graphs
PREDICTION_ROOT=/path/to/hamgnn-predictions
MODEL_SOURCE=/path/to/checkpoint-used-for-these-predictions
HAMGNN_ROUTE=/path/to/hamgnn-route
OVERLAP_ROOT=/path/to/direct-overlap
START=1
END=100
NPROC=1
export OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1
```

## Generate eigenstates

Each graph file must contain exactly one graph. Predictions must store onsite
blocks followed by offsite blocks in the matching graph order. Hamiltonian
values are in Hartree; the overlap is dimensionless. Supported padded AO masks
are `13`, `15`, `27` and `40`; select the one used by the graph generator and
confirm it matches the actual orbital files. Unsupported masks are rejected.

```bash
NAO_MAX=13
"$WFC_PYTHON" "$WORKFLOWS/hamgnn/wfc_hamgnn.py" \
  --graph-data-path "$GRAPH_ROOT/{index}/graph_data.npz" \
  --hamiltonian-path "$PREDICTION_ROOT/{index}/prediction_hamiltonian.npy" \
  --model-source "$MODEL_SOURCE" --nao-max "$NAO_MAX" --dtype float32 \
  --save-pattern "$HAMGNN_ROUTE/{index}/SPIN0" \
  --start "$START" --end "$END" --index-width 4 --nproc "$NPROC" \
  --summary "$HAMGNN_ROUTE/wfc-summary.json"
```

The default expects a full predicted Hamiltonian. Use `--fix-edge-index` only
when the upstream model explicitly predicts a residual to be added to genuine
graph `Hon0/Hoff0` blocks. Do not add H0 again to a full prediction. Optionally
set `--expected-orbitals` to require the known full AO dimension.

Workers load one frame at a time and are recycled periodically. See the
[shared data and restart contract](../README.md#supported-data) for atomic
frame publication and validated skipping of completed outputs.

## Reuse AO overlaps and run NAC

`OVERLAP_ROOT` must contain the outputs of
[`abacus/direct_overlap.py`](../abacus/direct_overlap.py), generated from the
declared SCF trajectory. Generate them with the
[ABACUS overlap step](../abacus/README.md#generate-adjacent-frame-ao-overlaps)
if they are not already available. Geometry, AO basis and ordering must agree
with the HamGNN graphs; the AO overlap depends on these inputs.

Set `ROUTE="$HAMGNN_ROUTE"` and `SOURCE=hamgnn`, then follow
[common NAC projection](../common/README.md) to link the overlaps and select
the physical band window and effective frame spacing.
